## Presets

`build_scenario(name)` returns `(MissionConfig, skip_leop)`. The presets are `leop_24h` (24 hours, startup), `no_leop_24h` (24 hours, skip startup), and `leop_1yr` (8760 hours, startup). Each sets its matching output tag and a six-hour telemetry flush interval. Configuration imports come from `antara_models`, not the running simulator.

Explicit CLI values override presets, which override global defaults. Supplying `--step-sec` selects fixed stepping unless `--coarse-step-sec` is also supplied. See the [Science guide](ANTARA_Science_Sim.md) for all switches.

```bash
python src/ANTARA_Science_Sim.py --scenario leop_24h --duration-hours 1 --step-sec 2 --no-plots
```

Science writes flat paths such as `results/science/leop_24h_ANTARA_Science_telemetry.csv`. Reusing a tag overwrites files. Configure a separate `output_tag` programmatically for independent experiments; there is no output-tag CLI switch.

## Verify actual duration

```python
import pandas as pd

df = pd.read_csv("results/science/leop_24h_ANTARA_Science_telemetry.csv", low_memory=False)
assert not df.empty and "mode" in df
print("Rows:", len(df), "Modes:", df["mode"].unique())
print("Hours:", (df.time_sec.iloc[-1] - df.time_sec.iloc[0]) / 3600)
print("Intervals:", sorted(df.time_sec.diff().dropna().unique()))
```

## Comparison tool limitations

As of 2026-09-28, the `compare_scenarios.py` CLI streams selected scalar columns in 10,000-row chunks with one-row lookahead. It honors `--results-dir` and supports flat prefixed, nested prefixed and legacy unprefixed nested telemetry. Detector arrays and unused event tables are not loaded by the CLI. The older `load_scenario_data` Python helper still loads full frames and is intended for small callers.

It writes `scenario_comparison.csv` and `scenario_comparison.png` to `--output-dir`. Use `--require-all` to reject missing scenarios; nightly additionally uses `--require-full-duration` to require complete, monotonic 24h/24h/8760h telemetry starting at zero. Without the latter flag, bounded studies can still be compared. Duty cycles and averages use elapsed-time weights. Current interval metadata must agree with timestamps and end-state times; complete runs require a zero-duration final observation. Legacy files without duration metadata derive weights from adjacent timestamps. Invalid time accounting fails before comparison artifacts are published. See [telemetry integrity checks](TELEMETRY_INTEGRITY_REPAIR.md).

For current recovery evidence, see the [runtime report](SIMULATION_RUNTIME_FIX_REPORT.md).

## Comparison input integrity (September 27)

For the legacy full-frame loader, empty optional mode-transition, SAA-pass and ground-contact CSVs are accepted as
zero events, matching the simulator's output when none occurred. Empty required
telemetry and malformed event CSVs are not suppressed. Every telemetry row must
have a recognized Science mode; missing or unknown labels fail instead of
reducing duty-cycle totals silently. Saturation/eclipsing flags accept explicit
True/False or 0/1 representations, including their CSV strings. Invalid or
missing comparison flags raise errors rather than being counted as true.

The streaming summary uses the same mode validation and Boolean encodings;
missing scalar flags remain visible through its duration-coverage fields.
See [verification](TELEMETRY_INTEGRITY_REPAIR.md).

Science/downlink byte totals sum every interval increment, including final
histogram flushes; they are not duration-weighted. Missing counter columns appear
as unavailable (blank CSV values), not zero. Present columns containing missing,
negative, infinite or malformed values fail validation. Zero generated bytes
means downlink efficiency is undefined, even when both byte totals are zero.

Even without `--require-full-duration`, current-format telemetry must end with
a zero-duration observation. A bounded study is supported; an unfinished CSV is
not a completed study. Legacy timestamp-only files still infer zero weight for
their last row, so their completion cannot be independently established from
interval metadata. The full-duration flag additionally checks preset endpoints.
