# ============================================================
# Orekit Python Wrapper (NOT on PyPI - must build from source)
# ============================================================
# Orekit is a Java astrodynamics library. The Python wrapper uses JCC
# and must be built from source. Pre-built wheels are not available on PyPI.
#
# Build instructions:
# 1. Install Java 11+ and JCC: pip install jcc
# 2. Clone Orekit: git clone https://gitlab.orekit.org/orekit/orekit.git
# 3. Build wrapper: cd orekit && python setup.py build_ext --inplace
# 4. Install: pip install -e .
#
# The orekit package provides: import orekit; orekit.initVM()
# Actual Orekit JARs are downloaded at runtime by init_orekit_data().
#
# Java 11+ must be installed separately.
# ============================================================

# Core scientific computing stack
